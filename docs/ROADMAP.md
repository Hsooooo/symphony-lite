# Symphony Lite 남은 작업 로드맵

> 현재 Phase 1~3 완료 기준. 남은 작업들을 우선순위, 난이도, 예상 소요시간과 함께 정리합니다.

## 📊 현재 진행 상황

```
Phase 1: 핵심 API + React UI + Docker Compose              ✅ 완료
Phase 2: MCP 서버 완성 + Kimi 연동 가이드                   ✅ 완료
Phase 3: 상태 머신 + 하이브리드 승인 + 프로젝트 멤버 + 인프라 정보  ✅ 완료
Phase 4: WORKFLOW.md 파싱 및 프로젝트별 템플릿                ⬜ 미완료
Phase 5: 인증/권한 + 모니터링                               ⬜ 미완료
Phase 6: 고도화 (자동화, 검색, 알림)                         ⬜ 미완료
```

| 3 | **프론트엔드 로그인 UI** | 로그인/회원가입 페이지, JWT 토큰 저장(localStorage), 인증된 요청 | 하 | 2~3시간 | ⬜ |
| 4 | **MCP 서버 인증** | API 키 또는 JWT로 MCP tool 호출 인증. 현재는 누구나 호출 가능 | 중 | 2~3시간 | ⬜ |
